```text
## 功能名称：餐厅收藏

### 功能描述
在实验 7-1 美食助手的基础上，为用户增加餐厅收藏功能。每个餐厅卡片上显示收藏图标，用户点击后可收藏/取消收藏，收藏的餐厅在右侧新增的“我的收藏”面板中展示。

### 输入
- 餐厅 ID：string，必填
- 操作类型：add / remove，必填

### 输出
- 收藏成功：图标变为实心❤️，toast 提示“已添加收藏”
- 取消收藏：图标变为空心❤️，toast 提示“已取消收藏”
- 操作失败：toast 提示“操作失败，请重试”

### 约束条件
- 最多收藏 20 家餐厅，超出时提示“收藏夹已满（最多20家）”
- 收藏数据使用 localStorage 持久化存储，页面刷新后状态保持
- 同一餐厅不能重复收藏
- 新增“我的收藏”面板位于页面右侧、地图下方
- 收藏面板中点击餐厅，地图自动定位到该餐厅并弹出详情

### 验收标准
- [ ] 每个餐厅卡片上显示收藏图标（空心/实心）
- [ ] 点击图标可正常添加/取消收藏
- [ ] 刷新页面后收藏状态保持
- [ ] 收藏超过 20 家时提示上限
- [ ] “我的收藏”面板正确显示列表
- [ ] 点击收藏列表餐厅，地图定位并弹出详情
```
