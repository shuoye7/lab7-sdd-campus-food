# 最近搜索 SDD 提示词

```text
正式任务还要实现第二项功能“最近搜索”。请保持餐厅收藏功能，并按规范驱动流程补齐需求、设计和任务。

功能要求：
1. 成功提交非空搜索关键词后记录最近搜索。
2. 最多保存 8 项，最近使用在前，相同关键词去重并提位。
3. 空关键词、价格筛选、口味筛选和排序操作不记录。
4. 最近搜索使用 localStorage 持久化。
5. 点击关键词回填搜索框并立即执行搜索。
6. 支持整体清空并提示“已清空最近搜索”。
7. 没有记录时不占位。
8. 读取脏数据时执行清洗，关键词最多 50 字符。
9. 不新增后端接口、第三方依赖或构建配置。

请先生成 recent-search 的 spec.md、design.md、tasks.md，再与餐厅收藏一起进入代码实现。
```
